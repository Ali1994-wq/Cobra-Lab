Cobra Lab

منصة الأمن السيبراني الدفاعي

Cobra Lab مشروع قيد التطوير لبناء لوحة تحكم عربية باتجاه الكتابة من اليمين إلى اليسار (RTL)، لإدارة السجلات الأمنية ومتابعة الأجهزة والتهديدات.

الحالة الحالية

تتضمن النسخة الأولية من الواجهة:

- تسجيل الأجهزة المُدارة يدويًا وحفظ بياناتها محليًا في المتصفح.
- حساب بصمة SHA-256 لملف يختاره المستخدم دون رفع الملف إلى خادم.
- تسجيل ملاحظات التهديدات يدويًا وتحديد مستوى خطورتها التقديري.
- سجل أحداث محلي وإمكانية تصديره إلى CSV.
- واجهة متجاوبة مع شاشات الهواتف والحواسيب.

حدود النسخة الحالية

هذه النسخة واجهة أولية وليست منصة أمن سيبراني متكاملة.

- لا يوجد اتصال بخادم خلفي أو قاعدة بيانات.
- لا يوجد محرك فعلي لاكتشاف البرمجيات الخبيثة.
- حساب SHA-256 لا يحدد وحده ما إذا كان الملف ضارًا.
- لا يجري اكتشاف الأجهزة أو مراقبتها تلقائيًا.
- لا توجد وظائف فعلية لمسح الشبكات أو عزل الأجهزة عن بُعد.
- البيانات المحلية قد تُفقد عند مسح بيانات المتصفح أو تغيير الجهاز.

التشغيل

افتح "index.html" في متصفح حديث.

يُفضّل تشغيل الواجهة عبر HTTPS عند اختبار وظائف التشفير التي تتطلب سياقًا آمنًا.

النشر

يمكن نشر الواجهة الثابتة باستخدام GitHub Pages بعد إعداد النشر وتفعيله من إعدادات المستودع.

استضافة الملفات الثابتة لا توفر تلقائيًا خادم API أو قاعدة بيانات أو محرك فحص أمني.

مبادئ السلامة

- استخدم الأدوات على الأجهزة والشبكات التي تملكها أو لديك تصريح صريح بإدارتها.
- لا تضع كلمات المرور أو مفاتيح API أو البيانات الحساسة داخل المستودع العام.
- لا تعتبر السجلات اليدوية أو بصمة الملف بديلًا عن الفحص الأمني المتخصص.
- اختبر الوظائف الجديدة في بيئة مصرح بها قبل استخدامها عمليًا.

خارطة الطريق

1. اختبار الواجهة على الهواتف والحواسيب.
2. إعداد النشر عبر HTTPS والتحقق من عمله.
3. إضافة اختبارات آلية أساسية.
4. تحديد بنية خلفية آمنة عند الحاجة إلى تخزين مركزي ومصادقة.
5. إضافة وظائف أمنية فعلية باستخدام مكونات موثوقة وصلاحيات واضحة.
6. اختبار الوظائف وتوثيق نتائجها قبل اعتبارها جاهزة للاستخدام.

حالة المشروع

المشروع قيد التطوير. يجب التمييز بوضوح بين الوظائف الموجودة في الواجهة والقدرات الأمنية الفعلية التي لم تُنفذ بعد.
